# Deus Ex: Human Revolution — Director’s Cut — PT-BR para Wii U

**Download atual: v1.1 — assistente de instalação para Windows e Mac.**

- [Baixar o ZIP](https://github.com/hugopsousa-dev/dxhr-ptbr-wiiu/releases/latest/download/DXHR_PTBR_WiiU.zip)
- [Como instalar, passo a passo](COMO_INSTALAR.md)
- [Ler o guia no navegador](https://hugopsousa-dev.github.io/guias/DXHR-PTBR.html)

Região **USA / NTSC-U** · Title ID `000500001012BA00`. O pacote contém deltas e código próprio; você fornece os arquivos da sua cópia do jogo. O assistente gera a pasta `wiiu`; não copie `patches` para o SD. Aroma precisa ter SDCafiine instalado e ativado separadamente.

**Correção importante:** o ZIP v1.0 foi empacotado com arquivos de Zelda e Title IDs incorretos. Use v1.1. Os IDs 00050000101C9400/00050000101C9500 não são de Deus Ex.
